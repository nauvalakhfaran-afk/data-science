Pengertian

Data science adalah ilmu untuk mengolah data agar data itu bisa menjadi informasi yang bisa bermanfaat bagi perusahaan atau orang orang

Alur Data Science

1. Pemahaman Bisnis (Business Understanding): Langkah awal adalah mengidentifikasi tujuan utama proyek melalui diskusi mendalam dengan pemangku kepentingan untuk memahami masalah yang ingin diselesaikan dan pertanyaan spesifik yang perlu dijawab melalui data

2. Penggalian Data (Data Collection/Mining): Setelah tujuan ditetapkan, data yang relevan dikumpulkan dari berbagai sumber, baik internal maupun eksternal seperti melalui web scraping atau API Penting untuk memastikan data tersebut representatif untuk menjawab masalah yang ada

3. Pembersihan Data (Data Cleaning): Karena data yang diambil sering kali tidak sempurna, tahap ini dilakukan untuk memperbaiki kualitas data Prosesnya meliputi pengisian nilai yang hilang (missing values), menangani data yang menyimpang (outlier), serta melakukan normalisasi atau standarisasi agar model memberikan hasil yang baik

4. Eksplorasi Data (EDA - Exploratory Data Analysis): Tahap ini bertujuan memahami pola dan hubungan dalam data menggunakan teknik statistik dan visualisasi, seperti histogram untuk melihat distribusi, scatter plot untuk hubungan antar variabel, dan heatmap untuk korelasi Hasil dari EDA digunakan untuk menemukan hipotesis yang akan diuji pada pemodelan

5. Rekayasa Fitur (Feature Engineering): Ini adalah proses memilih, menciptakan, atau mengubah data mentah menjadi fitur yang lebih bermanfaat bagi model Teknik yang digunakan meliputi feature selection (memilih variabel relevan), feature transformation (seperti one-hot encoding), dan pengurangan dimensi untuk menyederhanakan data

6. Pemodelan Prediktif (Predictive Modeling): Tahap ini merupakan inti dari Data Science di mana algoritma Machine Learning digunakan untuk membangun model berdasarkan masalah yang dihadapi, seperti klasifikasi, clustering, atau regresi Data dibagi menjadi data pelatihan, validasi, dan testing untuk memastikan kualitas, kemudian dievaluasi menggunakan metrik seperti akurasi, recall, presisi, dan f1-score

7. Visualisasi Data: Hasil akhir dari analisis disampaikan kepada pemangku kepentingan melalui visualisasi data Penentuan jenis plot yang tepat sangat berpengaruh agar hasil analisis dapat dimengerti dan membantu dalam pengambilan keputusan
